# 登录说明

## 首次登录

1. 启动 BFBTCode Desktop。
2. 在欢迎页选择“登录”。
3. 使用账号和密码，或按页面提供的授权方式完成登录。
4. 根据提示完成验证码或设备确认。
5. 登录成功后返回 Desktop 主页面。

## 登录失败

请检查网络、账号信息、系统时间和服务状态。不要把密码或验证码提交到 Issue。反馈问题时只提供系统版本、BFBTCode 版本、错误提示和复现步骤。

## 退出与重新登录

在账号菜单中选择退出登录。共享电脑使用完毕后必须退出，并清除不属于自己的账号信息。

登录后请阅读 [Desktop 设置](../settings/README.md) 和 [基本使用](../usage/README.md)。

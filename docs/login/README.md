# 登录说明

官网账号同时用于 BFBT Code 和 DTworkeasy，不需要再注册。用手机号注册，日常用账号和密码登录。

## 注册

1. 打开官网 <https://www.dtrony.com>，点击「注册」。
2. 填写可接收短信的手机号，获取验证码。
3. 设置密码后完成注册。

请勿把验证码或密码告诉任何人。

## 登录客户端

1. 启动 BFBT Code 桌面版、终端版或 DTworkeasy。
2. 使用官网同一套账号和密码登录。
3. 登录成功后返回主页面。

Windows / Linux 上的 BFBT Code 和 BFBTbridge 需要试用或会员有效期内才能使用。DTworkeasy 注册即可免费使用。

## 修改密码

登录官网后打开用户中心，按提示修改密码。

## 忘记密码

在登录窗口选择「找回密码」，用注册手机号验证后设置新密码。

## 登录失败

请检查网络、账号信息、系统时间和会员状态。不要把密码或验证码提交到 Issue。反馈问题时只提供系统版本、软件版本、错误提示和复现步骤。

## 退出与重新登录

- 桌面版：在账号菜单中选择退出登录。
- 终端版：输入 `/logout`，或执行 `bfbtcodetui --daemon logout`。
- 共享电脑使用完毕后必须退出。

登录后请阅读 [Desktop 设置](../settings/README.md) 和 [第一次使用](../usage/README.md)。

# BFBT Code 文档导航

**BFBT Code** 是东复同科技的 AI 编程助手（AI coding agent / coding assistant），用于写代码、学习和日常工作。桌面版支持 Windows 与 macOS（Apple Silicon），另有 Linux 终端版（TUI）。本仓库面向普通用户，不要求阅读源码或自行编译。说明与官网 <https://www.dtrony.com> 保持一致。

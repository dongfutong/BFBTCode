# 用手机远控 BFBT Code 桌面版

手机安装 DTworkeasy，电脑安装 BFBT Code 桌面版，用**同一套东复同账号**登录。

## 电脑上准备

1. 打开 **BFBTcode**，登录账号。
2. 在设置里填写大模型 API Key，先在电脑上发一句「你好」确认能回复。
3. 打开一个工作文件夹。
4. 点右侧面板的「远程」。
5. 点「启用远程连接」，等到中继状态显示 online。
6. 点「生成配对二维码」。也可以改用连接号和远程密码。

二维码大约两分钟内有效。过期就再生成一次。

## 手机上连接

1. 打开 DTworkeasy，用同一账号登录。
2. 进入「我的电脑」或 AI 聊里的设备列表。
3. 扫描电脑上的二维码，或把 `dtworkeasy://pair?...` 链接粘贴进去，确认配对。
4. 点刚绑定的电脑，进入远控会话。
5. 选择工作区和会话，就可以发任务。电脑上会真正执行。

请保持电脑开机、BFBTcode 开着，并且已经登录。电脑休眠或退出登录后，手机会显示电脑不在线。电脑上的 BFBT Code 必须处于试用或会员可用状态，过期后无法远控。

## 使用时注意

- 电脑上如果弹出权限确认，需要在电脑或手机上点允许，任务才会继续。
- 同账号无需再加白名单。其他账号远控：在电脑设置白名单中加入对方手机号或用户名，对方扫码后即可连接。
- 手机功能菜单可将当前大模型设置保存到电脑。
- 把手机借给别人用时，请先在电脑上关闭远程连接。

# Desktop 设置说明

Desktop 设置页面用于配置语言、账号、工作目录、模型服务、远程连接和安全选项。

## 语言

打开「设置→语言」，选择界面语言并按提示重新加载。当前 Desktop 支持：简体中文、繁體中文、English、日本語、한국어、Español、Português、Русский、العربية、हिन्दी、বাংলা、தமிழ்、བོད་སྐད、Bahasa Indonesia。

## 模型服务

在模型服务设置中选择服务商并填写服务地址、模型名称和 API Key。没有 API Key，软件无法回复。API Key 只保存到自己的设备，不要提交到仓库或 Issue。

手机远控时，可在 DTworkeasy 功能菜单里把模型配置「保存到电脑」，写入当前这台主机。

## 工作目录

选择需要协助的项目目录。只授予完成任务所需的目录权限；不要把密码库、私钥、生产环境配置或包含个人信息的目录作为工作目录。

## 远程连接

点右侧面板的「远程」，启用远程连接并等到中继状态显示 online，再生成配对二维码。同账号无需再加白名单。其他账号远控时，在电脑设置白名单中加入对方手机号或用户名。详见 [用手机远控桌面版](../remote/desktop.md)。

## 权限与安全

对文件写入、命令执行、网络访问等操作逐项确认。发现异常行为时停止任务并保留脱敏日志。

## 账号与会员

账号区域可查看登录状态、会员有效期和退出登录。BFBT Code 需要试用或会员有效期内才能使用。会员购买方式见 [会员权益](../token/README.md)。

# 安装说明

## 支持的安装包

请在 [Releases](../../releases) 选择最新稳定版本：

| 系统 | 常见文件 | 说明 |
|---|---|---|
| Windows 10/11 64 位 | `.msi` 或 `.exe` | 普通用户推荐 |
| macOS | `.dmg` | 打开后拖入 Applications |
| Linux 64 位 | `.deb`、`.rpm` 或 `.AppImage` | 选择发行版对应格式 |

当前 Release 中实际提供的格式可能随版本变化，请以下载页面为准。

## Windows

1. 下载 Windows 安装包。
2. 双击运行，按安装向导完成安装。
3. 从开始菜单或桌面快捷方式启动 BFBTCode。
4. 若 Windows SmartScreen 提示风险，请先确认文件来自本仓库 Release，并核对 Release 提供的校验值；不要运行来源不明的安装包。

## macOS

1. 下载 `.dmg` 文件并打开。
2. 将 BFBTCode 拖入 Applications。
3. 首次启动若系统阻止打开，请在“系统设置→隐私与安全性”中确认允许已从官方 Release 下载的应用。

## Linux

- Debian/Ubuntu：使用发行版的软件包安装器打开 `.deb`。
- Fedora/RHEL：使用软件包安装器打开 `.rpm`。
- AppImage：赋予执行权限后运行。

安装完成后请继续阅读 [登录说明](../login/README.md)。

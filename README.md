# BFBTCode 用户文档与安装包

BFBTCode 是面向普通用户的 AI 编程助手。本仓库只提供**程序安装包、下载安装说明、登录说明、使用说明、Desktop 设置说明和 Token 服务说明**，不包含 BFBTCode 源代码。

## 快速开始

1. 打开 [Releases](../../releases) 下载与你的系统匹配的安装包。
2. 按照 [安装说明](docs/install/README.md) 完成安装。
3. 启动 BFBTCode，阅读 [登录说明](docs/login/README.md)。
4. 在 Desktop 设置中配置模型服务，然后开始使用 [使用说明](docs/usage/README.md)。

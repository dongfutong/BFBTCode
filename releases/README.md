# 安装包目录

最新 BFBT Code 安装包请从官网下载中心或 GitHub Releases 获取，不要把本目录里的历史文件当作当前版本。

| | |
|---|---|
| 官网下载中心 | <https://www.dtrony.com> |
| GitHub Releases | <https://github.com/dongfutong/BFBTCode/releases> |
| 当前最新 | [`v1.0.8.26102008`](https://github.com/dongfutong/BFBTCode/releases/tag/v1.0.8.26102008) |

当前与官网一致的安装包：

- Windows 10/11 x64：`BFBTcode_1.0.8.26102008_x64_en-US.msi`（BFBT Code 桌面版，试用或会员）
- macOS Apple Silicon：`BFBTcode_1.0.8.26102009_aarch64.dmg`（BFBT Code 桌面版，试用或会员；Intel Mac 暂未提供）
- Linux x86_64 TUI：推荐 `curl -fsSL 'https://www.dtrony.com/install-tui.sh' | sudo sh`；Release 亦附 `bfbtcodetui-linux-x86_64.tar.gz`
- Android DTworkeasy：见 [DTworkeasy-Mobile](https://github.com/dongfutong/DTworkeasy-Mobile/releases)
- iOS DTworkeasy：[App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)

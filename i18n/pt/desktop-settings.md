# Configurações do Desktop

Site oficial: <https://www.dtrony.com> · Documentação: <https://www.dtrony.com/docs>

O BFBT Code para desktop (Windows / macOS) exige teste ou assinatura. A assinatura não inclui tokens do modelo.

Em Configurações, altere o idioma, configure o provedor do modelo, escolha a pasta de trabalho, gerencie permissões e consulte o uso de Tokens. Confirme o provedor antes de salvar uma API Key e não publique segredos em capturas, Issues ou logs.

# BFBT Code — agente de programação com IA / AI coding agent

**BFBT Code** é um assistente de programação com IA (AI coding assistant) da Dongfutong (东复同科技) para escrever código, aprender e o trabalho do dia a dia. Há app desktop para **Windows** e **macOS (Apple Silicon)** e uma edição de terminal **Linux** (TUI). Controle o agente no computador pelo telefone com o DTworkeasy.

Este repositório publica **instaladores e documentação de usuário**, não o código-fonte.

Baixe o instalador em [Releases](https://github.com/dongfutong/BFBTCode/releases) e siga o [guia de instalação](../../docs/install/README.md). Não baixe nem compile o código-fonte.

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`); Intel Mac ainda não está disponível
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (grátis após o cadastro)
- iOS: DTworkeasy na [App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)

Entre com a conta oficial Dongfutong. O BFBT Code e o BFBTbridge exigem período de teste ou assinatura (90 dias de teste na inscrição); o DTworkeasy é gratuito após o cadastro. A assinatura não inclui tokens do modelo.

# BFBTCode ユーザーガイド

公式サイト：<https://www.dtrony.com>

[Releases](../../releases) からインストーラーをダウンロードし、[インストール手順](../../docs/install/README.md) に従ってください。ソースコードのダウンロードやビルドは不要です。

- Windows：BFBT Code Desktop 1.0.0（`.msi`）
- Linux：BFBT Code TUI 1.0.0（`bfbtcodetui`）
- Android：DTworkeasy 1.0.6（`.apk`）
- macOS / iOS：未公開

東復同の公式アカウントでログインします。BFBT Code は試用または会員期間が必要です。DTworkeasy は登録後無料です。

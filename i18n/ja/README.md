# BFBTCode ユーザーガイド

[Releases](../../releases) から対応するインストーラーをダウンロードし、[インストールガイド](../../docs/install/README.md)に従ってください。Desktop にログインし、作業フォルダーを選び、タスクを入力します。ファイル変更・コマンド・ネットワーク操作は確認してください。

設定で言語、モデル、API Key、作業フォルダー、権限を設定します。Token は公式購入画面だけで購入し、パスワードや API Key とともに公開しないでください。問題は秘密情報を削除して Issue に報告してください。

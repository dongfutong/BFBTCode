# BFBT Code — AI コーディングエージェント / AI coding agent

**BFBT Code** は東復同科技（Dongfutong）の AI コーディングアシスタントです。コードを書く、学ぶ、日常の作業に使えます。**Windows** と **macOS（Apple Silicon）** のデスクトップ版、および **Linux** 端末版（TUI）があります。スマートフォンの DTworkeasy からパソコン上の BFBT Code を遠隔操作できます。

このリポジトリはインストーラーとユーザー向けドキュメントのみを公開し、ソースコードは含みません。

[Releases](https://github.com/dongfutong/BFBTCode/releases) からインストーラーをダウンロードし、[インストール手順](../../docs/install/README.md) に従ってください。ソースコードのダウンロードやビルドは不要です。

- Windows：BFBT Code Desktop（`.msi`）
- macOS Apple Silicon：BFBT Code Desktop（`.dmg`）。Intel Mac は未提供
- Linux：BFBT Code TUI（`bfbtcodetui`）
- Android：DTworkeasy（登録後無料）
- iOS：DTworkeasy（[App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)）

東復同の公式アカウントでログインします。BFBT Code と BFBTbridge は試用または会員期間が必要です（新規登録で 90 日試用）。DTworkeasy は登録後無料です。会員費にモデル Token は含まれません。

# Desktop सेटिंग्स

आधिकारिक साइट: <https://www.dtrony.com> · दस्तावेज़: <https://www.dtrony.com/docs>

BFBT Code डेस्कटॉप (Windows / macOS) के लिए ट्रायल या सदस्यता चाहिए। सदस्यता में मॉडल टोकन शामिल नहीं हैं।

सेटिंग्स में भाषा बदलें, मॉडल प्रदाता कॉन्फ़िगर करें, कार्य फ़ोल्डर चुनें, अनुमतियाँ प्रबंधित करें और Token उपयोग देखें। API Key सहेजने से पहले प्रदाता की पुष्टि करें और स्क्रीनशॉट, Issue या लॉग में रहस्य साझा न करें।

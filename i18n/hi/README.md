# BFBT Code — AI कोडिंग एजेंट / AI coding agent

**BFBT Code** डोंगफूतोंग (东复同科技) का AI कोडिंग असिस्टेंट है — कोड लिखने, सीखने और रोज़मर्रा के काम के लिए। **Windows** और **macOS (Apple Silicon)** डेस्कटॉप ऐप तथा **Linux** टर्मिनल (TUI) संस्करण उपलब्ध हैं। फ़ोन पर DTworkeasy से कंप्यूटर वाले BFBT Code को रिमोट कंट्रोल किया जा सकता है।

यह रिपॉज़िटरी केवल इंस्टॉलर और उपयोगकर्ता दस्तावेज़ प्रकाशित करती है, सोर्स कोड नहीं।

[Releases](https://github.com/dongfutong/BFBTCode/releases) से इंस्टॉलर डाउनलोड करें, फिर [इंस्टॉलेशन गाइड](../../docs/install/README.md) देखें। सोर्स कोड डाउनलोड या कंपाइल करने की आवश्यकता नहीं है।

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`); Intel Mac अभी उपलब्ध नहीं
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (पंजीकरण के बाद मुफ़्त)
- iOS: DTworkeasy ([App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230))

आधिकारिक Dongfutong खाते से साइन इन करें। BFBT Code और BFBTbridge के लिए ट्रायल या सदस्यता चाहिए (पंजीकरण पर 90 दिन का ट्रायल); DTworkeasy पंजीकरण के बाद मुफ़्त है। सदस्यता शुल्क में मॉडल टोकन शामिल नहीं हैं।

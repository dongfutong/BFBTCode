# BFBTCode उपयोगकर्ता मार्गदर्शिका

[Releases](../../releases) से सही इंस्टॉलर डाउनलोड करें और [इंस्टॉलेशन गाइड](../../docs/install/README.md) पढ़ें। Desktop खोलकर लॉग इन करें, कार्य फ़ोल्डर चुनें और कार्य लिखें। फ़ाइल, कमांड और नेटवर्क क्रियाओं की समीक्षा करें।

सेटिंग्स में भाषा, मॉडल, API Key, फ़ोल्डर और अनुमतियाँ बदलें। Token केवल आधिकारिक पृष्ठ से खरीदें और पासवर्ड, कुंजी या Token प्रकाशित न करें। Issue भेजने से पहले संवेदनशील जानकारी हटाएँ।

# BFBTCode उपयोगकर्ता मार्गदर्शिका

आधिकारिक साइट: <https://www.dtrony.com>

[Releases](../../releases) से इंस्टॉलर डाउनलोड करें, फिर [इंस्टॉलेशन गाइड](../../docs/install/README.md) देखें। सोर्स कोड डाउनलोड या कंपाइल करने की आवश्यकता नहीं है।

- Windows: BFBT Code Desktop 1.0.0 (`.msi`)
- Linux: BFBT Code TUI 1.0.0 (`bfbtcodetui`)
- Android: DTworkeasy 1.0.6 (`.apk`)
- macOS / iOS: अभी उपलब्ध नहीं

आधिकारिक Dongfutong खाते से साइन इन करें। BFBT Code के लिए ट्रायल या सदस्यता चाहिए; DTworkeasy पंजीकरण के बाद मुफ़्त है।

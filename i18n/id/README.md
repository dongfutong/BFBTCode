# BFBT Code — agen pengodean AI / AI coding agent

**BFBT Code** adalah asisten pengodean AI (AI coding assistant) dari Dongfutong (东复同科技) untuk menulis kode, belajar, dan pekerjaan sehari-hari. Tersedia aplikasi desktop **Windows** dan **macOS (Apple Silicon)**, serta edisi terminal **Linux** (TUI). Kendalikan agen di komputer dari ponsel dengan DTworkeasy.

Repositori ini hanya menerbitkan **pemasang dan dokumentasi pengguna**, bukan kode sumber.

Unduh pemasang dari [Releases](https://github.com/dongfutong/BFBTCode/releases), lalu ikuti [panduan instalasi](../../docs/install/README.md). Tidak perlu mengunduh atau mengompilasi kode sumber.

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`); Intel Mac belum tersedia
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (gratis setelah pendaftaran)
- iOS: DTworkeasy di [App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)

Masuk dengan akun resmi Dongfutong. BFBT Code dan BFBTbridge memerlukan masa uji coba atau keanggotaan (uji coba 90 hari saat daftar); DTworkeasy gratis setelah pendaftaran. Biaya keanggotaan tidak mencakup token model.

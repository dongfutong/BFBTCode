# Setelan Desktop

Situs resmi: <https://www.dtrony.com> · Dokumentasi: <https://www.dtrony.com/docs>

BFBT Code desktop (Windows / macOS) memerlukan masa uji coba atau keanggotaan. Biaya keanggotaan tidak mencakup token model.

Di Setelan, Anda dapat mengganti bahasa, mengatur penyedia model, memilih folder kerja, mengelola izin, dan melihat penggunaan Token. Pastikan penyedia sebelum menyimpan API Key. Jangan membagikan rahasia dalam tangkapan layar, Issue, atau log.

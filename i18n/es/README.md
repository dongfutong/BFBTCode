# BFBT Code — agente de programación con IA / AI coding agent

**BFBT Code** es un asistente de programación con IA (AI coding assistant) de Dongfutong (东复同科技) para escribir código, aprender y el trabajo diario. Hay app de escritorio para **Windows** y **macOS (Apple Silicon)**, y una edición de terminal **Linux** (TUI). Puede controlar el agente del ordenador desde el teléfono con DTworkeasy.

Este repositorio publica **instaladores y documentación de usuario**, no el código fuente.

Descargue el instalador desde [Releases](https://github.com/dongfutong/BFBTCode/releases) y siga la [guía de instalación](../../docs/install/README.md). No descargue ni compile el código fuente.

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`); Intel Mac aún no está disponible
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (gratis tras el registro)
- iOS: DTworkeasy en el [App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)

Inicie sesión con la cuenta oficial de Dongfutong. BFBT Code y BFBTbridge requieren prueba o membresía (90 días de prueba al registrarse); DTworkeasy es gratuito tras el registro. La membresía no incluye tokens del modelo.

# Ajustes de Desktop

Sitio oficial: <https://www.dtrony.com> · Documentación: <https://www.dtrony.com/docs>

BFBT Code para escritorio (Windows / macOS) requiere prueba o membresía. La membresía no incluye tokens del modelo.

En Ajustes puedes cambiar el idioma, configurar el proveedor del modelo, elegir la carpeta de trabajo, administrar permisos y consultar el uso de Tokens. Verifica el proveedor antes de guardar una API Key y no publiques secretos en capturas, Issues ni registros.

# BFBTCode 用户指南（简体中文）

## 下载与安装
从 [Releases](../../releases) 下载 Windows、macOS 或 Linux 对应安装包，按 [安装说明](../../docs/install/README.md) 完成安装。不要下载或编译源码。

## 登录与使用
启动 Desktop，选择“登录”，完成账号验证后选择工作目录，在输入框描述任务，并审查模型提出的文件修改、命令和网络操作。

## Desktop 设置
在“设置”中配置语言、账号、模型服务、API Key、工作目录和权限。当前支持 14 种界面语言。API Key、密码和 Token 不得上传到仓库或 Issue。

## Token 购买
在账号或用量页面进入官方购买入口，选择套餐并完成支付；到账后刷新余额。Token 与 API Key 不同，泄露后应立即撤销或更换。详见 [Token 说明](../../docs/token/README.md)。

问题请提交 [GitHub Issue](https://github.com/dongfutong/BFBTCode/issues) 或 [Gitee Issue](https://gitee.com/dongfutong2026/bfbtcode/issues)，并删除所有敏感信息。

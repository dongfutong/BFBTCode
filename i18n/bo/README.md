# BFBT Code — AI ཀོཌ་བྱེད་པོ། / AI coding agent

**BFBT Code** ནི་ཏུང་ཧྥུ་ཐུང་（东复同科技）གི AI ཀོཌ་རོགས་པ་ཡིན། ཀོཌ་འབྲི་བ་དང་སློབ་སྦྱོང་、ཉིན་རེའི་ལས་ཀར་བེད་སྤྱོད་བྱེད། **Windows** དང་ **macOS (Apple Silicon)** ཅོག་ངོས་ཆས་、**Linux** ཚོད་འཛིན་པར་མ（TUI）ཡོད། ཁ་པར་གྱི་ DTworkeasy ནས་གློག་ཀླད་ནང་གི་ BFBT Code རྒྱང་བཀོལ་བྱེད་ཐུབ།

[Releases](https://github.com/dongfutong/BFBTCode/releases) ནས་སྒྲིག་འཇུག་ཡིག་ཆ་ཕབ་ལེན་བྱས་ནས [སྒྲིག་འཇུག་ལམ་སྟོན](../../docs/install/README.md) ལྟར་བྱོས། མ་ཡིག་ཕབ་ལེན་དང་བསྒྲིག་བཟོ་མི་དགོས།

- Android: DTworkeasy（ཐོ་འགོད་རྗེས་རིན་མེད།）
- iOS: DTworkeasy ([App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230))

# BFBTCode 사용자 가이드

공식 사이트: <https://www.dtrony.com>

[Releases](../../releases)에서 설치 파일을 받은 뒤 [설치 안내](../../docs/install/README.md)를 따르세요. 소스 코드를 받거나 직접 빌드할 필요는 없습니다.

- Windows: BFBT Code Desktop 1.0.0 (`.msi`)
- Linux: BFBT Code TUI 1.0.0 (`bfbtcodetui`)
- Android: DTworkeasy 1.0.6 (`.apk`)
- macOS / iOS: 아직 제공하지 않습니다

동복동 공식 계정으로 로그인합니다. BFBT Code는 체험 또는 회원 기간이 필요합니다. DTworkeasy는 가입 후 무료입니다.

# BFBT Code — AI 코딩 에이전트 / AI coding agent

**BFBT Code**는 동복동 과학기술(Dongfutong)의 AI 코딩 어시스턴트입니다. 코드 작성, 학습, 일상 업무에 사용합니다. **Windows**와 **macOS(Apple Silicon)** 데스크톱 앱, **Linux** 터미널(TUI) 버전이 있습니다. 휴대폰의 DTworkeasy로 컴퓨터의 BFBT Code를 원격 제어할 수 있습니다.

이 저장소는 설치 파일과 사용자 문서만 제공하며 소스 코드는 포함하지 않습니다.

[Releases](https://github.com/dongfutong/BFBTCode/releases)에서 설치 파일을 받은 뒤 [설치 안내](../../docs/install/README.md)를 따르세요. 소스 코드를 받거나 직접 빌드할 필요는 없습니다.

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`). Intel Mac은 아직 없습니다
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (가입 후 무료)
- iOS: DTworkeasy ([App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230))

동복동 공식 계정으로 로그인합니다. BFBT Code와 BFBTbridge는 체험 또는 회원 기간이 필요합니다(신규 가입 시 90일 체험). DTworkeasy는 가입 후 무료입니다. 회원비에는 모델 토큰이 포함되지 않습니다.

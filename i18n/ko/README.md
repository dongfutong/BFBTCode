# BFBTCode 사용자 안내

[Releases](../../releases)에서 운영 체제에 맞는 설치 파일을 내려받고 [설치 안내](../../docs/install/README.md)를 따르세요. Desktop에 로그인하고 작업 폴더를 선택한 뒤 작업을 입력합니다. 파일, 명령, 네트워크 작업은 확인 후 승인하세요.

설정에서 언어, 모델, API Key, 작업 폴더와 권한을 설정합니다. Token은 공식 구매 화면에서만 구매하고 비밀번호·API Key·Token을 공개하지 마세요. 민감 정보를 제거한 뒤 Issue로 문제를 신고하세요.

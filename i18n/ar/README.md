# دليل مستخدم BFBTCode

الموقع الرسمي: <https://www.dtrony.com>

حمّل حزمة التثبيت من [Releases](../../releases) ثم اتبع [دليل التثبيت](../../docs/install/README.md). لا حاجة لتنزيل الشيفرة المصدرية أو تجميعها.

- Windows: BFBT Code Desktop 1.0.0 (`.msi`)
- Linux: BFBT Code TUI 1.0.0 (`bfbtcodetui`)
- Android: DTworkeasy 1.0.6 (`.apk`)
- macOS / iOS: غير متاح حالياً

سجّل الدخول بحساب دونغفوتونغ الرسمي. يتطلب BFBT Code وBFBTbridge فترة تجريبية أو عضوية؛ DTworkeasy مجاني بعد التسجيل.

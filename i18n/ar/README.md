# BFBT Code — وكيل برمجة بالذكاء الاصطناعي / AI coding agent

**BFBT Code** مساعد برمجة بالذكاء الاصطناعي (AI coding assistant) من دونغفوتونغ (东复同科技) لكتابة الشفرة والتعلّم والعمل اليومي. يتوفر تطبيق سطح مكتب لـ **Windows** و**macOS (Apple Silicon)** وإصدار طرفية **Linux** (TUI). يمكن تشغيل الوكيل على الحاسوب من الهاتف عبر DTworkeasy.

ينشر هذا المستودع **حزم التثبيت ووثائق المستخدم فقط**، دون الشيفرة المصدرية.

حمّل حزمة التثبيت من [Releases](https://github.com/dongfutong/BFBTCode/releases) ثم اتبع [دليل التثبيت](../../docs/install/README.md). لا حاجة لتنزيل الشيفرة المصدرية أو تجميعها.

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`)؛ أجهزة Intel غير متاحة حالياً
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (مجاني بعد التسجيل)
- iOS: DTworkeasy على [App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)

سجّل الدخول بحساب دونغفوتونغ الرسمي. يتطلب BFBT Code وBFBTbridge فترة تجريبية أو عضوية (90 يوماً عند التسجيل)؛ DTworkeasy مجاني بعد التسجيل. رسوم العضوية لا تشمل رموز النموذج.

# إعدادات Desktop

الموقع الرسمي: <https://www.dtrony.com> · التوثيق: <https://www.dtrony.com/docs>

يتطلب تطبيق BFBT Code لسطح المكتب (Windows / macOS) فترة تجريبية أو عضوية. الرسوم لا تشمل رموز النموذج.

من الإعدادات يمكنك تغيير اللغة، إعداد مزود النموذج، اختيار مجلد العمل، إدارة الصلاحيات وعرض استخدام Tokens. تحقق من المزود قبل حفظ API Key ولا تنشر الأسرار في لقطات الشاشة أو Issues أو السجلات.

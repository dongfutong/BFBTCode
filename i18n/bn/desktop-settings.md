# Desktop সেটিংস

অফিসিয়াল সাইট: <https://www.dtrony.com> · ডকুমেন্ট: <https://www.dtrony.com/docs>

BFBT Code ডেস্কটপ (Windows / macOS) এর জন্য ট্রায়াল বা সদস্যপদ লাগে। সদস্যপদে মডেল টোকেন থাকে না।

সেটিংসে ভাষা পরিবর্তন, মডেল প্রদানকারী কনফিগার, কাজের ফোল্ডার নির্বাচন, অনুমতি পরিচালনা এবং Token ব্যবহার দেখা যায়। API Key সংরক্ষণের আগে প্রদানকারী যাচাই করুন এবং স্ক্রিনশট, Issue বা লগে গোপন তথ্য প্রকাশ করবেন না।

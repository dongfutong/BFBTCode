# BFBTCode ব্যবহারকারী নির্দেশিকা

[Releases](../../releases) থেকে সঠিক ইনস্টলার ডাউনলোড করে [ইনস্টল নির্দেশিকা](../../docs/install/README.md) অনুসরণ করুন। Desktop-এ লগইন করুন, কাজের ফোল্ডার বাছুন এবং কাজ লিখুন। ফাইল, কমান্ড ও নেটওয়ার্ক কার্যক্রম যাচাই করুন।

সেটিংসে ভাষা, মডেল, API Key, ফোল্ডার ও অনুমতি নির্ধারণ করুন। শুধু অফিসিয়াল পৃষ্ঠা থেকে Token কিনুন; পাসওয়ার্ড, কী বা Token প্রকাশ করবেন না। Issue পাঠানোর আগে সংবেদনশীল তথ্য মুছে ফেলুন।

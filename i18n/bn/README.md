# BFBTCode ব্যবহারকারী নির্দেশিকা

অফিসিয়াল সাইট: <https://www.dtrony.com>

[Releases](../../releases) থেকে ইনস্টলার ডাউনলোড করুন, তারপর [ইনস্টলেশন গাইড](../../docs/install/README.md) অনুসরণ করুন। সোর্স কোড ডাউনলোড বা কম্পাইল করার দরকার নেই।

- Windows: BFBT Code Desktop 1.0.0 (`.msi`)
- Linux: BFBT Code TUI 1.0.0 (`bfbtcodetui`)
- Android: DTworkeasy 1.0.6 (`.apk`)
- macOS / iOS: এখনও উপলব্ধ নয়

অফিসিয়াল Dongfutong অ্যাকাউন্ট দিয়ে সাইন ইন করুন। BFBT Code এবং BFBTbridge-এর জন্য ট্রায়াল বা সদস্যপদ লাগে; DTworkeasy নিবন্ধনের পর বিনামূল্যে।

# BFBT Code — AI কোডিং এজেন্ট / AI coding agent

**BFBT Code** ডংফুটং (东复同科技) এর AI কোডিং অ্যাসিস্ট্যান্ট — কোড লেখা, শেখা এবং দৈনন্দিন কাজের জন্য। **Windows** ও **macOS (Apple Silicon)** ডেস্কটপ অ্যাপ এবং **Linux** টার্মিনাল (TUI) সংস্করণ আছে। ফোনের DTworkeasy দিয়ে কম্পিউটারের BFBT Code রিমোট কন্ট্রোল করা যায়।

এই রিপোজিটরি শুধু ইনস্টলার ও ব্যবহারকারী ডকুমেন্ট প্রকাশ করে, সোর্স কোড নয়।

[Releases](https://github.com/dongfutong/BFBTCode/releases) থেকে ইনস্টলার ডাউনলোড করুন, তারপর [ইনস্টলেশন গাইড](../../docs/install/README.md) অনুসরণ করুন। সোর্স কোড ডাউনলোড বা কম্পাইল করার দরকার নেই।

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`); Intel Mac এখনও নেই
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (নিবন্ধনের পর বিনামূল্যে)
- iOS: DTworkeasy ([App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230))

অফিসিয়াল Dongfutong অ্যাকাউন্ট দিয়ে সাইন ইন করুন। BFBT Code এবং BFBTbridge-এর জন্য ট্রায়াল বা সদস্যপদ লাগে (নিবন্ধনে ৯০ দিনের ট্রায়াল); DTworkeasy নিবন্ধনের পর বিনামূল্যে। সদস্যপদ ফিতে মডেল টোকেন থাকে না।

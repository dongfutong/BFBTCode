# BFBT Code — AI 程式設計助手 / AI coding agent

**BFBT Code** 是東復同科技推出的 AI 程式設計助手（AI coding agent / coding assistant），用於寫程式、學習與日常工作。桌面版支援 **Windows** 與 **macOS（Apple Silicon）**，另有 **Linux** 終端機版（TUI）。可用手機上的 DTworkeasy 遠端控制電腦裡的 BFBT Code。

本倉庫只提供安裝包與使用說明，不含原始碼。

| 會員 | [會員權益](../../docs/token/README.md) |

從 [GitHub Releases](https://github.com/dongfutong/BFBTCode/releases) 下載適合系統的安裝包，依 [安裝說明](../../docs/install/README.md) 安裝。不要下載或編譯原始碼。

- Windows：BFBT Code 桌面版（`.msi`）
- macOS Apple Silicon：BFBT Code 桌面版（`.dmg`）；Intel Mac 尚未提供
- Linux：BFBT Code 終端機版（`bfbtcodetui`）
- Android：DTworkeasy（註冊即可免費使用）
- iOS：DTworkeasy（[App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)）

啟動後用東復同官網帳號登入。BFBT Code 和 BFBTbridge 需試用或會員有效期（新帳號有 90 天試用）；DTworkeasy 註冊即可免費使用。請先設定模型 API Key。完整說明以簡體中文與官網為準。

# BFBTCode 使用指南（繁體中文）

官網：<https://www.dtrony.com>

從 [Releases](../../releases) 下載適合系統的安裝包，依 [安裝說明](../../docs/install/README.md) 安裝。不要下載或編譯原始碼。

- Windows：BFBT Code 桌面版 1.0.0（`.msi`）
- Linux：BFBT Code 終端版 1.0.0（`bfbtcodetui`）
- Android：DTworkeasy 1.0.6（`.apk`）
- macOS / iOS：尚未上架

啟動後用東復同官網帳號登入。BFBT Code 和 BFBTbridge 需試用或會員有效期；DTworkeasy 註冊即可免費使用。請先設定模型 API Key。完整說明以簡體中文與官網為準。

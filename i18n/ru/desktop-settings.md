# Настройки Desktop

Официальный сайт: <https://www.dtrony.com> · Документация: <https://www.dtrony.com/docs>

Настольный BFBT Code (Windows / macOS) требует пробный период или членство. Взнос не включает токены модели.

В настройках можно изменить язык, настроить поставщика модели, выбрать рабочую папку, управлять разрешениями и просматривать использование Token. Проверьте поставщика перед сохранением API Key и не публикуйте секреты в снимках, Issue или журналах.

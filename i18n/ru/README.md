# BFBT Code — ИИ-агент для программирования / AI coding agent

**BFBT Code** — ИИ-помощник программиста (AI coding assistant) компании Dongfutong (东复同科技) для написания кода, обучения и повседневной работы. Есть приложения для **Windows** и **macOS (Apple Silicon)** и терминальная версия для **Linux** (TUI). Управлять агентом на компьютере можно с телефона через DTworkeasy.

В этом репозитории публикуются **установщики и пользовательская документация**, исходный код не входит.

Скачайте установщик со страницы [Releases](https://github.com/dongfutong/BFBTCode/releases) и следуйте [инструкции по установке](../../docs/install/README.md). Исходный код скачивать и собирать не нужно.

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`); Intel Mac пока недоступен
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (бесплатно после регистрации)
- iOS: DTworkeasy в [App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)

Войдите с официальной учётной записью Dongfutong. BFBT Code и BFBTbridge требуют пробный период или членство (90 дней после регистрации); DTworkeasy бесплатен после регистрации. Членский взнос не включает токены модели.

# Руководство BFBTCode

Скачайте подходящий установщик на странице [Releases](../../releases) и следуйте [инструкции установки](../../docs/install/README.md). Запустите Desktop, войдите, выберите рабочую папку и опишите задачу. Проверяйте действия с файлами, командами и сетью.

В настройках задаются язык, модель, API Key, папка и разрешения. Покупайте Token только на официальной странице и не публикуйте пароли, ключи или Token. Перед Issue удалите конфиденциальные данные.

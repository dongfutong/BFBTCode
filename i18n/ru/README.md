# Руководство пользователя BFBTCode

Официальный сайт: <https://www.dtrony.com>

Скачайте установщик со страницы [Releases](../../releases) и следуйте [инструкции по установке](../../docs/install/README.md). Исходный код скачивать и собирать не нужно.

- Windows: BFBT Code Desktop 1.0.0 (`.msi`)
- Linux: BFBT Code TUI 1.0.0 (`bfbtcodetui`)
- Android: DTworkeasy 1.0.6 (`.apk`)
- macOS / iOS: пока недоступно

Войдите с официальной учётной записью Dongfutong. BFBT Code и BFBTbridge требуют пробный период или членство; DTworkeasy бесплатен после регистрации.

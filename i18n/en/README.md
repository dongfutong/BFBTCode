# BFBT Code — AI coding agent and coding assistant

**BFBT Code** is an AI coding agent / coding assistant from Dongfutong (东复同科技) for writing code, learning, and everyday work. Use the **Windows** and **macOS (Apple Silicon)** desktop app, or the **Linux** terminal (TUI) edition. Drive the agent on your computer from your phone with DTworkeasy.

This repository ships **installers and user docs only** — not BFBT Code source code.

| | |
|---|---|
| Website | <https://www.dtrony.com> |
| Docs | <https://www.dtrony.com/docs> |
| Download | [GitHub Releases](https://github.com/dongfutong/BFBTCode/releases) |
| Membership | [Trial and membership](../../docs/token/README.md) |

BFBT Code and BFBTbridge require an active **trial or membership**. New accounts get a **90-day trial**. DTworkeasy is free after registration. Membership does not include model tokens; set your own API key before chatting.

## Platforms

- Windows 10/11 64-bit: BFBT Code Desktop (`.msi`) — trial or membership
- macOS 11+ Apple Silicon: BFBT Code Desktop (`.dmg`) — trial or membership; Intel Macs are not available yet
- Linux x86_64: BFBT Code TUI (`bfbtcodetui`) — trial or membership
- Android: DTworkeasy (free after registration) — [DTworkeasy-Mobile](https://github.com/dongfutong/DTworkeasy-Mobile/releases)
- iOS: DTworkeasy on the [App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230)

Linux one-line install:

```
curl -fsSL 'https://www.dtrony.com/install-tui.sh' | sudo sh
```

Sign in with the same Dongfutong account used on the website. Follow the [installation guide](../../docs/install/README.md), then [sign-in](../../docs/login/README.md) and [first-run](../../docs/usage/README.md). Use Settings for language, model provider, API key, workspace, remote access, and permissions.

The Simplified Chinese guides and <https://www.dtrony.com/docs> are authoritative if translations differ.

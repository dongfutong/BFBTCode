# BFBTCode User Guide

Download the matching installer from [Releases](../../releases), then follow the [installation guide](../../docs/install/README.md). Start Desktop, sign in, choose a workspace, and describe your task. Review and approve file, command, and network actions.

Use Settings to configure language, model provider, API key, workspace, and permissions. Buy Tokens only through the official purchase page. Tokens are not passwords or provider API keys; never publish them. Report issues through GitHub or Gitee with secrets removed.

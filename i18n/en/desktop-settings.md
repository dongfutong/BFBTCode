# Desktop Settings

Official site: <https://www.dtrony.com> · Docs: <https://www.dtrony.com/docs>

BFBT Code desktop (Windows / macOS) requires an active trial or membership. Membership does not include model tokens.

Use Settings to switch language, configure the model provider, choose a workspace, manage remote access and permissions, and check membership status. Confirm that the API key comes from the official provider before saving. Never put API keys, passwords, or tokens in screenshots, issues, or logs.

During phone remote control, DTworkeasy can save the current model settings onto this computer.

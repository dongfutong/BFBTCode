# Desktop அமைப்புகள்

அதிகாரப்பூர்வ தளம்: <https://www.dtrony.com> · ஆவணங்கள்: <https://www.dtrony.com/docs>

BFBT Code டெஸ்க்டாப் (Windows / macOS)க்கு சோதனை அல்லது உறுப்பினர் தேவை. உறுப்பினர் கட்டணத்தில் மாதிரி டோக்கன்கள் இல்லை.

அமைப்புகளில் மொழியை மாற்றவும், மாதிரி வழங்குநரை அமைக்கவும், பணிக் கோப்புறையைத் தேர்ந்தெடுக்கவும், அனுமதிகளை நிர்வகிக்கவும், Token பயன்பாட்டைப் பார்க்கவும். API Key சேமிப்பதற்கு முன் வழங்குநரைச் சரிபார்த்து, ஸ்கிரீன்ஷாட், Issue அல்லது பதிவுகளில் ரகசியங்களை வெளியிட வேண்டாம்.

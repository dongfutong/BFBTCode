# BFBTCode பயனர் வழிகாட்டி

அதிகாரப்பூர்வ தளம்: <https://www.dtrony.com>

[Releases](../../releases) இலிருந்து நிறுவியைப் பதிவிறக்கி [நிறுவல் வழிகாட்டியை](../../docs/install/README.md) பின்பற்றவும். மூலக் குறியீட்டைப் பதிவிறக்கவோ தொகுக்கவோ வேண்டாம்.

- Windows: BFBT Code Desktop 1.0.0 (`.msi`)
- Linux: BFBT Code TUI 1.0.0 (`bfbtcodetui`)
- Android: DTworkeasy 1.0.6 (`.apk`)
- macOS / iOS: இன்னும் வழங்கப்படவில்லை

அதிகாரப்பூர்வ Dongfutong கணக்கில் உள்நுழையவும். BFBT Code மற்றும் BFBTbridgeக்கு சோதனை அல்லது உறுப்பினர் தேவை; DTworkeasy பதிவுக்குப் பிறகு இலவசம்.

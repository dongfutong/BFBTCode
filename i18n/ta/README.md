# BFBT Code — AI குறியீட்டு முகவர் / AI coding agent

**BFBT Code** என்பது Dongfutong (东复同科技) வழங்கும் AI குறியீட்டு உதவியாளர். குறியீடு எழுத, கற்க, அன்றாட பணிக்குப் பயன்படும். **Windows** மற்றும் **macOS (Apple Silicon)** டெஸ்க்டாப் செயலி, **Linux** முனையப் பதிப்பு (TUI) உள்ளன. தொலைபேசியில் DTworkeasy மூலம் கணினியில் உள்ள BFBT Code-ஐ தொலை கட்டுப்படுத்தலாம்.

இந்தக் களஞ்சியம் நிறுவிகளையும் பயனர் ஆவணங்களையும் மட்டுமே வெளியிடுகிறது; மூலக் குறியீடு இல்லை.

[Releases](https://github.com/dongfutong/BFBTCode/releases) இலிருந்து நிறுவியைப் பதிவிறக்கி [நிறுவல் வழிகாட்டியை](../../docs/install/README.md) பின்பற்றவும். மூலக் குறியீட்டைப் பதிவிறக்கவோ தொகுக்கவோ வேண்டாம்.

- Windows: BFBT Code Desktop (`.msi`)
- macOS Apple Silicon: BFBT Code Desktop (`.dmg`); Intel Mac இன்னும் இல்லை
- Linux: BFBT Code TUI (`bfbtcodetui`)
- Android: DTworkeasy (பதிவுக்குப் பிறகு இலவசம்)
- iOS: DTworkeasy ([App Store](https://apps.apple.com/cn/app/dtworkeasy/id6806894230))

அதிகாரப்பூர்வ Dongfutong கணக்கில் உள்நுழையவும். BFBT Code மற்றும் BFBTbridgeக்கு சோதனை அல்லது உறுப்பினர் தேவை (பதிவில் 90 நாள் சோதனை); DTworkeasy பதிவுக்குப் பிறகு இலவசம். உறுப்பினர் கட்டணத்தில் மாதிரி டோக்கன்கள் இல்லை.

# BFBTCode பயனர் வழிகாட்டி

[Releases](../../releases) இலிருந்து சரியான நிறுவியைப் பதிவிறக்கி [நிறுவல் வழிகாட்டியை](../../docs/install/README.md) பின்பற்றவும். Desktop-ல் உள்நுழைந்து, பணிக் கோப்புறையைத் தேர்ந்தெடுத்து பணியை எழுதவும். கோப்பு, கட்டளை, வலைச் செயல்களை மதிப்பாய்வு செய்யவும்.

அமைப்புகளில் மொழி, மாதிரி, API Key, கோப்புறை மற்றும் அனுமதிகளை அமைக்கவும். அதிகாரப்பூர்வ பக்கத்தில் மட்டுமே Token வாங்கவும்; கடவுச்சொல், விசை அல்லது Token வெளியிட வேண்டாம். Issue முன் ரகசியத் தகவலை அகற்றவும்.
